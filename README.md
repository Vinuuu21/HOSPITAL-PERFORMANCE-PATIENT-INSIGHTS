# HOSPITAL-PERFORMANCE-PATIENT-INSIGHTS
Developed an interactive Hospital Patient Analytics Dashboard using Power BI to analyze patient admissions, department-wise distribution, gender demographics, billing amounts, and average length of stay. Created KPI cards and interactive visualizations to identify healthcare trends and support data-driven decision-making.
Hospital Patient Analytics Dashboard

Project Overview
Analyzed hospital patient data using Power BI to understand patient admissions, department-wise distribution, gender demographics, billing amounts, and average length of stay.

Tools Used
* Power BI
* Data Visualization
* DAX
* Data Cleaning

Key Insights
* Analyzed patient distribution across hospital departments.
* Examined gender demographics and monthly patient admissions.
* Tracked total billing amount and average length of stay.
* Created an interactive dashboard to visualize healthcare trends and support data-driven decision-making.

Objective

To monitor hospital performance, understand patient trends, and support data-driven healthcare management.

How to View the Dashboard

1. Download the .pbix file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive visualizations and patient analytics.
